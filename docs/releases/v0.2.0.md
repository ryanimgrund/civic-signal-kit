# Civic Signal Kit 0.2.0

This release makes Civic Signal Kit more useful for reproducible public-interest reporting workflows.

## Highlights

- Markdown and JSON outputs now include threshold metadata and method notes.
- The CLI can write summaries to files with `--output`.
- The CLI can return exit code `3` with `--fail-on-notes` when data-quality notes are present.
- Added a synthetic service-demand example.
- Added use-case and pilot-plan documentation for educators, journalists, community groups, and civic volunteers.

## Verification

```sh
PYTHONPATH=src python3 -m unittest discover -s tests
```

Expected result:

```text
Ran 9 tests
OK
```

## Known Limitations

- The package is not yet published to PyPI.
- Examples are synthetic and should not be used for real-world decisions.
- The toolkit summarizes data; it does not provide medical, legal, financial, or emergency advice.

## Privacy And Security

Civic Signal Kit runs locally, uses only the Python standard library, and does not include analytics, tracking, telemetry, or remote logging.
