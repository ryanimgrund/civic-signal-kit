# Support

Civic Signal Kit is maintained as a small open-source project.

## Questions

Open a GitHub issue with the `question` label and include:

- What you are trying to summarize.
- A small anonymized CSV sample if possible.
- The command you ran.
- The output you expected.

## Bugs

Use the bug report template. Do not include sensitive or identifiable data.

## Security

Follow [SECURITY.md](SECURITY.md) for vulnerability reports.
